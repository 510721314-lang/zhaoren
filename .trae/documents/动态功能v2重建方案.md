# 服务动态功能 v2 重建实施方案（v2 · 专家审查修订版）

## 1. 背景与目标

**问题**：2026-10-02 提交 `18b6808`「提审整改批次1」为清理提审包，删除了 v1 动态功能全套前端（`pages/blog`、`pages/blog-publish`、`pages/blog-detail`、`pages/user-home`），并移除「我的」页博客入口与 `partner-detail` 动态卡片。用户在模拟器发现「我的 → 我的动态 / 发布动态」消失，希望在 `pages-v2` 下重建。

**目标**：以 v2 规范重建动态功能；**云端 `blog-action` 零改动**（完整可用），新增前端页面 + 恢复入口 + 接通「推荐耍伴 → 卡片最新动态」数据源。

## 2. 决策记录

**用户拍板（最终）**：
1. 范围：**完整三页**（我的动态 / 发布动态 / 动态详情）+ **TA 的动态流** + **完整恢复「推荐耍伴 → 卡片最新动态」**（含云函数改动）
2. 实施时机：**现在就全量做**
3. 3B 爽约行为走查：**挂起**

**专家审查结论（已采纳为结构性约束，非改需求）**：
- **提审风险为已知并接受的风险**（见 §7.1）——该功能系提审整改主动移除，现在重建存在再次被拒风险；用户已知情并选择继续。
- **按"可独立验收的最小增量 + 部署边界"分批**，而非一次交付（§3）。
- **「推荐耍伴」性质是新功能**（数据源从未接通过），虽在本次范围内，但**独立成批、独立门禁与验收**，不与动态三页混做。
- **3B 走查挂起**需在 `docs/deploy-log.md` 明确标注（随首批提交补记）。

## 6. 核心实现要点

### 6.1 新页面统一约定
- `.json`：`{"navigationStyle":"custom","enablePullDownRefresh":true,"backgroundTextStyle":"dark","usingComponents":{"nav-bar":"/components/nav-bar/index"}}`
- `.js`：页面自带本地 `callCloud`（照抄 `my-demands.js:7`）
- `.wxml` 首行 `<view class="v2 bl">`（detail `bd`、publish `bp`）+ `<nav-bar title="{{navTitle}}">`
- 登录守卫一律 `wx.getStorageSync('v2_login_ok')`（**禁用** `app.globalData.userInfo`，v2 恒 null）

### 6.2 `blog`（信息流）
- `data`：`scope('feed'|'my'|'author')`、`authorOpenid`、`activeScene`、`activeTopic`、`list/page/hasMore/loading/loadingMore/showEmpty`
- `onLoad`：读 `scope/authorOpenid/tag`（`tag` 命中 `TOPIC_NAMES` 才生效）；`navTitle` my→「我的动态」/author→「TA的动态」/feed→「动态」
- 取数：`my`→`my_list`；`author`→`feed_list`+`author_openid`；`feed`→`feed_list`（可带 `scene`/`tag`）
- `onShow` 刷新、`onPullDownRefresh`、`onReachBottom` 分页；`decorate()` 预处理（WXML 不做逻辑）

### 6.3 `blog-detail`
- action：`detail`/`comment_list`/`like`/`unlike`/`comment_add`/`delete_my`/`comment_delete`
- `toggleLike`：乐观更新 + 失败双回滚 + `this._liking` 防连点；`onShareTimeline`/`onShareAppMessage` 路径改 v2

### 6.4 `blog-publish`
- `MAX_IMAGES=9`、`CONTENT_MAX=1000`、`MAX_TAGS=3`；上传 `wx.cloud.uploadFile({cloudPath:'blog/'+Date.now()+'_'+rand+'.jpg'})`
- `onSubmit`：`guardSwitch('blog')` → 校验 → `blog-action {action:'publish', content, images:fileIds, scene, tags}`；保留底部**社区规范提示**

### 6.5 「推荐耍伴」数据源（批次 3，落点：扩 `demand-publish.detail`）
- **理由**：上下文原生可得；单 RTT；**只部署 1 个云函数**；降级干净。
- **helper** `buildRecommendPartners(d)`：
  1. 候选：`partner_profile.where({status:'approved', is_deleted:_.neq(true), accept_switch:_.neq(false), accept_scenes:d.scene, credit_score:_.gte(cfg.min_credit_take_order||600)}).orderBy('credit_score','desc').limit(20)`；空则去信用门槛重试；可选叠加 `city`。
  2. 富化（批量）：`user_account`（`openid:_.in([...])`）取昵称/头像/`partner_credit_score`；`blog_post`（`author_openid:_.in([...]), status:'normal'` desc）每作者取首条 → `latest_dynamic:{cover,title(≤40字),at}`；`order_count` 对 Top5 用 `order_main.count()`（失败置 0）。
  3. 派生：`partner_level`（内联 `creditLevelOf`）、`price_min/price_max`（`scene_rates[d.scene]` 分→元，兜底全局 min/max）、`distance_km`（可选，`haversineKm`）。
  4. 排序截断：信用分 desc → `slice(0,5)`；**降级** `try/catch → []`，`detail` 仍 `ok:true`。
- 返回对象必备（对齐 `partner-card`）：`openid/nickname/avatar/real_name_verified/face_verified/partner_credit_score/partner_level/accept_scenes/bio/price_min/price_max/latest_dynamic`；`order_count`（`on_time_rate` 无源→null，靠 §5.2 `statsText` 兜底）
- `demand-detail.__renderDemand`：`recommendPartners: Array.isArray(demand.recommend_partners) ? demand.recommend_partners : []`

## 7. 风险与边界

### 7.1 提审风险（已知并接受）
该功能系「提审整改批次1」主动移除。重建后**提审前必须**：① 复核当初移除的确切原因（审查意见/类目要求）；② 齐备 UGC 合规材料（类目/功能声明、内容安全、举报入口、删除能力、社区规范提示）；③ 跑 `zhaoren-audit` + `mp-pre-release-audit`。**提审门禁独立于开发，进入提审流程前停下请示。**

### 7.2 其它
- **主包体积**：新增约 30KB，余量充足。
- **登录态**：严格 `v2_login_ok`。
- **图片上传**：仅收 `cloud://` 且 <512 字符；≤9 张；`uploadingCount>0` 阻断；删除按 `path` 匹配。
- **内容安全**：`switch_blog===false`→`blog_disabled`；`msgSecCheck` 异常 fail-closed。
- **数据库索引（无 createIndex API → 控制台手工建）**：
  - `blog_post`：`{author_openid:1,status:1,created_at:-1}`、`{status:1,created_at:-1}`
  - `blog_comment`：`{post_id:1,created_at:1}`
  - `blog_like`：`{post_id:1,openid:1}` **唯一索引**
  - `partner_profile`：`{status:1,accept_switch:1,credit_score:-1}`、`{accept_scenes:1,status:1,credit_score:-1}`
  - `order_main`：`{partner_openid:1,is_deleted:1}`
- **幂等**：`like` 云端幂等；`publish`/`comment_add` 用 `submitting`/`sending` 防重。
- **分享链接**：全部改 `pages-v2/*`；旧 `/pages/blog/*` 分享链接 404（预期内）。
