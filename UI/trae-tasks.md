# TRAE 批次任务书（trae-tasks）
> 使用方法：在TRAE中先执行【任务0】建立项目骨架，然后按批次1→2→3逐个粘贴执行。
> 每次执行前确保 #Context 已挂载：PRD.md / design-tokens.md / pages-spec.md / mock-data.md / anchor-home.html

────────────────────────────────────────────
## 任务0：项目骨架（先执行一次）
────────────────────────────────────────────
【角色】资深微信小程序开发
【任务】基于原生小程序框架初始化项目：
1. 目录结构：
   /pages(16个页面目录,见pages-spec) /components /styles /config /mock /utils /images
2. app.json：注册全部16页面路径；tabBar自定义(custom:true)5位：首页/广场/(中央发布)/消息/我的
3. /styles/tokens.wxss：将design-tokens.md全部变量转为CSS custom properties，并生成常用工具类(.card .btn-primary .tag-xx .text-xx等)
4. /config/enums.js + /config/index.js：按mock-data.md第1、3节完整生成
5. /utils/redline.js：实现R1时间校验(isInRedline()判断23:00-06:00)、场景白名单校验、18岁校验、金额校验，供全局调用
6. /app.wxss 引入tokens.wxss；/app.js 挂载全局夜间遮罩逻辑(R1命中→所有页面显示遮罩组件)
【硬性规则】禁止硬编码色值字号；所有可运营参数只从config/index.js读取；一次输出全部文件。
【验收】npm run dev 无报错；页面路由全部可跳转(空白页可)；夜间23:00-06:00任意页面出现遮罩。
