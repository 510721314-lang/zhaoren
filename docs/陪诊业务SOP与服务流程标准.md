## 第一章 总则

### 1.1 服务定位

社会化陪同就医服务属于**辅助性就医服务**，具有以下三重属性界定：

| 它不是 | 它是 |
|---|---|
| 医疗服务（不能替代医生的诊断与治疗） | 帮助患者更好完成就医过程的**支持性服务** |
| 单纯的生活照料 | 具备医疗场景专业性的**流程协助服务** |
| 志愿服务 | 由依法登记机构提供的**有偿服务** |

### 1.2 主体资格

- 服务提供者必须是**依法登记的机构**，与志愿服务相区分。
- 机构应建立服务管理制度并接受社会监督。

### 1.3 关键术语

| 术语 | 定义 |
|---|---|
| **社会化陪同就医服务** | 由机构提供的、辅助患者完成就医过程的非医疗性服务 |
| **服务提供者** | 通过提供社会化陪同就医服务获取收益的机构 |
| **服务对象** | 因行动、认知、地域差异等原因导致就医不便者，或追求更好就医体验的个人 |
| **顾客** | 购买服务的一方（可与服务对象分离，如子女为父母购买） |
| **陪同就医服务人员** | 直接为服务对象提供服务的人员（下称"陪诊师"） |
| **服务支持人员** | 客服、调度、质控等后台支持岗位 |

> **注意**："服务对象"与"顾客"分离是常态场景。合同签订方为顾客，服务方案须同时获得顾客与服务对象同意。

### 1.4 制度底座（机构四项必备制度）

1. **人力资源管理制度**：人员准入、培训、健康证明核验、聘任合同、信息公示、分类分级与订单匹配
2. **信息管理制度**：按 GB/T 35273 要求管理信息，授权同意前提下收集使用，防止泄露与丢失
3. **安全管理制度**：服务对象风险评估、服务安全规范、多场景应急预案、投保、过程记录与追溯
4. **合同与收费管理制度**：书面/电子合同签订、收费标准公示、实际收费与公示一致

## 第二章 服务边界清单

> **本章为全员必背红线，是防范非法行医、侵权与合同违约风险的第一道防线。**

### 2.1 可为清单（12项）

须在**服务对象或其法定监护人同意**的前提下开展：

| 序号 | 服务项目 |
|---|---|
| 1 | 领取预约号、预约挂号 |
| 2 | 代买或代取基础医疗用品（轮椅、陪护床、一次性口罩等） |
| 3 | 引导服务对象至指定科室、检查室或治疗区域 |
| 4 | 预约检查、做检查准备 |
| 5 | 样本送检 |
| 6 | 代替排队等候 |
| 7 | 领取药物和检查结果（报告、化验单据），必要时代发快递 |
| 8 | 记录医生医嘱，协助医患沟通 |
| 9 | 代取、复印病历、诊断证明等医疗文书 |
| 10 | 办理缴费、出入院手续 |
| 11 | 生活辅助：预订交通工具、餐饮，临时保管物品等 |
| 12 | 情感支持：陪伴、倾听、回应、安抚 |

### 2.2 禁为清单（7项）

| 序号 | 禁止行为 |
|---|---|
| 1 | **判读检查结果** |
| 2 | **参与医疗操作** |
| 3 | **提供医疗建议** |
| 4 | **代替服务对象或家属选择、同意治疗方案** |
| 5 | **调整用药方案** |
| 6 | **隐瞒、篡改或选择性传递关键医疗信息** |
| 7 | **签署具有法律效力的医疗文书** |

### 2.3 附加禁令

- 严禁以任何形式**加价倒卖号源**
- 严禁**推荐药品或医疗机构**
- 严禁**虚假宣传**
- 严禁在社交平台发布服务对象病历、检查单等任何信息

### 2.4 司法风险警示（实证案例）

| 风险类型 | 典型案例 | 后果 |
|---|---|---|
| **医疗行为越界** | 陪诊师擅自解读检查报告并建议用药，患者服药后出现不良反应 | 认定构成**非法行医**，判处拘役 3 个月；另有案例被罚 8 万元 |
| **材料保管过失** | 陪诊代办人员将患者借出的病理切片放于家门口箱中保管，导致丢失 | 判决赔偿经济损失 2000 余元 + **精神损害抚慰金 2 万元**，二审维持 |
| **合同违约** | 陪诊师未按时陪同，导致患者错过专家号 | 判决承担违约责任，赔偿挂号费及交通费损失；另有案例因协议缺服务时间条款判赔 5 万元 |
| **隐私泄露** | 陪诊师将患者病历转发至社交媒体 | 判决赔偿**精神损害抚慰金 2 万元** |
| **非法经营** | 平台与"黄牛"勾结高价倒卖专家号 | 以非法经营罪立案，负责人获刑 2 年；上海某公司 4 人非法牟利 100 余万元被查处 |

> **司法认定标准**：法院明确陪诊师作为专门从事陪诊服务的人员，负有**高于普通人的"善良管理人注意义务"**。

## 第三章 组织与人员标准

### 3.1 陪诊师基本要求（强制项）

- 遵守医疗机构规章制度，**不扰乱诊疗秩序、不误导服务对象、不干预医务人员的专业决策**
- 参加**岗前培训并考核通过**
- **定期参加专项培训**
- 持**有效期内的健康证明**（机构定期核验）

### 3.2 职业道德与职业素养

- 具备同理心和人文关怀，能主动关怀服务对象身心状态
- 尊重服务对象的自主选择权、决策权、个人习惯和民族习俗
- 良好的责任心意识和守时观念
- 心理素质好，善于自我调节情绪
- **保护患者信息和隐私**

### 3.3 专业知识要求

| 类别 | 具体内容 |
|---|---|
| 医疗场景常识 | 挂号流程、医院和科室布局、终端服务设备使用方法 |
| 基本安全知识 | 医院应急疏散路线、常见突发意外（摔倒、晕厥）的应对 |
| 其他 | 满足服务正常开展所需的专业知识 |

### 3.4 职业能力要求

- **就医安排能力**：就诊信息梳理、就诊流程安排
- **协调与沟通能力**：协助医患沟通、就诊信息记录与转达
- **情感支持能力**：陪伴、倾听、回应、安抚
- **应急能力**

### 3.5 培训体系

机构应组织岗前培训，并定期提供专项在职培训，内容包括：

1. 合规性培训
2. 专业能力培训
3. 安全与应急培训
4. 心理健康培训
5. 人文素养培训

### 3.6 人员信息公示

机构应建立陪诊师信息公示机制，公示内容包括：

- **基本信息**：健康证明有效期、培训记录、服务年限、累计服务次数
- **专业技能**：擅长服务场景、掌握的特殊技能、过往服务评价

### 3.7 分级与派单

机构宜建立陪诊师**分类分级及订单匹配制度**，按服务评分、履约记录、专科匹配度等多维度标签派单。

## 第四章 服务流程标准（核心）

> 国标将服务全流程划分为 **服务信息提供 → 委托与受理 → 服务交付** 三阶段，并要求建立 **服务评价与改进** 闭环。本 SOP 在此基础上细化为可执行的作业步骤。

### 阶段一：服务信息提供（售前）

| 步骤 | 作业内容 | 标准要求 | 责任人 |
|---|---|---|---|
| 1.1 信息公示 | 平台/门店公示服务内容、项目、人员信息、收费标准、投诉渠道 | 服务信息应**真实、完整、清晰**，与实际服务交付一致 | 运营 |
| 1.2 咨询应答 | 提供服务相关事项的解释说明 | 咨询渠道**方便、快捷、畅通** | 客服 |
| 1.3 渠道建设 | 除线上平台外，为不使用智能手机的老年人提供**人工客服电话预约**和**社区网格员协助登记** | 覆盖数字弱势群体 | 运营 |

**服务平台必备功能**：
- 服务内容展示与项目选择
- 陪同人员信息展示与选择
- 服务预约
- 订单管理
- 在线支付与结算
- 服务评价与反馈
- 个人账号管理

> 平台应安全、可靠、稳定，能够满足服务需求。

---

### 阶段二：委托与受理（工单生成）

| 步骤 | 作业内容 | 关键控制点 | 责任人 |
|---|---|---|---|
| 2.1 需求采集 | 采集服务对象基本信息与需求 | 见下方《信息采集清单》 | 客服/陪诊师 |
| 2.2 风险评估 | 评估并识别服务对象风险 | **评估结果作为服务方案制定依据**；不能接受委托须说明理由 | 客服/质控 |
| 2.3 方案商定 | 与顾客或服务对象共同商定服务方案 | 方案须获顾客或服务对象**同意** | 客服 |
| 2.4 合同签订 | 订立服务合同 | 书面或电子合同，**平等、自愿、信息对称**，条款公平公正 | 客服 |
| 2.5 收费 | 按公示标准收费 | 实际收费须**符合公示标准** | 客服 |
| 2.6 排单派单 | 匹配陪诊师 | 按医院、时段、专科熟悉度、服务能力分级匹配 | 调度 |

#### 2.1 信息采集清单（必采项）

| 类别 | 字段 |
|---|---|
| 基础信息 | 姓名、年龄、性别、联系方式、紧急联系人及电话 |
| 就诊信息 | 医院、院区、科室、专家、就诊日期与时段、是否首诊、同行人数 |
| 健康状况 | 症状描述、既往病史、**过敏史**、当前用药情况、既往就诊结论 |
| 行动能力 | 是否行动便利、是否需要轮椅/拐杖、是否需要接送 |
| 材料情况 | 是否已有检查报告、影像片、病理切片等特殊材料（**重点标记**） |
| 特殊需求 | 是否需要病历复印、报告代寄、住院协助等增值服务 |

#### 2.3 服务方案九要素（缺一不可）

1. 服务对象信息
2. 服务核心目标
3. 服务项目
4. 服务时间和地点
5. 服务人员配置
6. 服务用品保障
7. 服务流程
8. **风险评估与应对预案**
9. 服务沟通机制

#### 2.4 服务合同必备条款

- 服务方案
- **服务费用及明细**（含单项服务单价、总价、可能产生的额外费用说明）
- **明确的服务时段**（起止时间）——缺此项曾导致判赔 5 万元
- 取消/改期规则
- **第三方托管预付金**机制
- **家属授权签字范围**（明确不含医疗文书代签）
- 隐私保护条款
- 违约责任与争议解决

### 阶段三：服务交付（现场执行）

#### 3.1 诊前准备（T-1 日）

| 序号 | 作业动作 | 标准 |
|---|---|---|
| 1 | **信息核对与确认** | 电话/微信联系顾客，核对病情、就诊需求，确认是否有新出现的症状或报告 |
| 2 | **服务边界讲清** | 提前同步服务内容、收费明细、服务时长、取消规则、改期政策；明确告知"能做/不做"清单 |
| 3 | **医院前置功课** | 查清楼层与科室位置、取号方式、签到规则、陪护政策、停车指引，规划**最优就诊路线** |
| 4 | **资料整理** | 既往病历、检查报告**按时间排序**整理入文件夹，便于医生快速查阅 |
| 5 | **物资准备** | 文件夹、纸笔、口罩、手提袋、充电宝、呕吐袋；按需备轮椅/拐杖 |
| 6 | **发送就诊提醒** | 就诊时间、集合地点、需携带证件（身份证/医保卡/就诊卡）、是否需空腹/憋尿等检查注意事项 |

#### 3.2 到院接应（T 日）

| 序号 | 作业动作 | 标准 |
|---|---|---|
| 1 | **提前到岗** | 提前 **15–30 分钟**抵达医院，完成取号、签到、排队准备 |
| 2 | **确认流程** | 与顾客确认当日流程安排与预计时长 |
| 3 | **告知到达** | 主动向顾客发送已到位信息，确认身份后交接 |
| 4 | **节点打卡** | 关键环节定位打卡、拍照存档（机构系统留痕） |

#### 3.3 院内陪同执行（核心环节）

| 环节 | 作业动作 | 红线提醒 |
|---|---|---|
| **签到取号** | 协助取号、办卡、签到 | 仅走**官方渠道**挂号，绝不购买/倒卖号源 |
| **候诊引导** | 引导至科室，代排队，告知各项等待时长 | 不扰乱诊疗秩序 |
| **问诊陪同** | 安静陪同；**代为描述病情**；现场文字记录医生**原话** | ❌不替患者作答、❌不主观猜测病情、❌不随意插话、❌不干预医生决策 |
| **缴费办理** | 协助/代办缴费，逐笔保留凭证 | 款项流水留痕，当日对账 |
| **检查陪同** | 合理排布顺序，**优先完成空腹、限时类项目**；样本送检；提醒检查前注意事项 | ❌不参与任何医疗操作 |
| **取药核对** | 核对药名、剂量、用法、服用周期、禁忌说明，逐条记录 | ❌不解读报告、❌不建议用药、❌不调整用药方案 |
| **报告领取** | 领取检查报告、化验单据，按需代发快递 | 妥善保管，防遗失（病理切片等不可替代物重点防护） |
| **出入院协助** | 办理出入院手续、押金缴纳，记录科室/床位/主管医生 | ❌不代签手术同意书等法律文书 |

#### 3.4 结束交接

| 序号 | 作业动作 | 标准 |
|---|---|---|
| 1 | **单据统一收纳** | 病历本、处方、缴费单、检查报告、影像片统一整理归类 |
| 2 | **医嘱标准化整理** | 当天出具**文字版医嘱**：用药方式、复查时间、注意禁忌、后续检查项目。**只转述医生原话，不私自解读、不夸大、不误导** |
| 3 | **当面交接确认** | 所有资料、物品**当面交付**，双方确认无遗漏、无丢失，签署《材料交接签收单》 |
| 4 | **安全送别** | 确认患者离开方式与安全；必要时协助预订交通工具 |

#### 3.5 服务交付交付物清单

每单交付至少包含以下 4 项：

1. 整理归档的纸质/电子病历资料
2. 文字版医嘱单
3. 费用凭证（缴费单据、发票）
4. 服务记录单（关键节点打卡记录）

### 阶段四：收尾与改进闭环

| 步骤 | 作业动作 | 时限 | 责任人 |
|---|---|---|---|
| 4.1 资料归档 | 专人存档，不外泄、不转发、**不发布至社交平台**；按约定到期清理（行业标杆做法：病历 3 天内销毁） | 当天 | 陪诊师 |
| 4.2 服务复盘 | 记录本次服务问题、特殊情况，更新客户档案 | 当天 | 陪诊师 |
| 4.3 轻回访 | 询问是否看懂医嘱、有无疑问 | **24 小时内** | 陪诊师 |
| 4.4 正式回访 | 确认用药是否按医嘱执行、检查是否需补做、是否需协助安排复诊 | **诊后 2–3 个工作日** | 客服/陪诊师 |
| 4.5 评价收集 | 收集顾客评价，纳入陪诊师分级与派单权重 | 诊后 3 日内 | 客服 |
| 4.6 投诉处理 | 投诉受理、调查、反馈、整改 | 按承诺时限闭环 | 质控 |
| 4.7 复诊提醒 | 提醒下次就诊时间、注意事项 | 适时 | 客服 |

> **回访环节最易被忽略，却是将服务从"一次性陪同"升级为"可信赖陪伴"的关键。**

## 第五章 专项场景作业指引

### 5.1 老年患者陪诊

- 优先安排具备老年照护经验、沟通能力强的陪诊师
- 提前确认是否使用智能手机，不会使用者引导至人工客服电话或社区登记渠道
- 行动不便者提前备好轮椅/拐杖，规划无障碍路线
- 医嘱转述须**放慢语速、反复确认**，必要时同步向家属书面同步

### 5.2 异地就医陪诊

- 提前完成医院/科室/专家匹配建议（**不推荐特定医疗机构**）
- 提前规划交通、住宿、院区周边餐饮
- 跨城材料（病理切片、影像片）**必须签署《材料交接签收单》**，全程随身不离手
- 预留充足的检查预约与报告等待时间

### 5.3 孕产妇、儿童陪诊

- 关注候诊时长与体力消耗，合理安排休息
- 儿童陪同须有监护人授权，不得单独带走儿童
- 孕产妇需关注突发状况，熟知产科急诊位置

### 5.4 行动不便/残障人士

- 服务前必须完成风险评估，评估辅具需求
- 提前确认医院无障碍设施、电梯位置、轮椅租赁点
- 转移、搀扶动作须接受专业培训后执行

### 5.5 代问诊/代办场景（高风险）

- 仅接受**书面授权明确**的代办事项
- 病理切片、影像片等不可替代材料：**必须当面签收、单独保管、当日归还**，绝不带回家中
- 严禁超出授权范围代签任何文书

## 第六章 应急预案与风险处置

> 机构应制定多场景突发事件应急预案，并**定期组织培训和应急演练**。

### 6.1 应急场景处置表

| 场景 | 处置动作 | 禁止行为 |
|---|---|---|
| **患者突发身体不适/晕厥/摔倒** | ①立即呼叫医院医护 ②联系紧急联系人 ③上报机构 ④保护现场、记录经过 | ❌**绝不私自施救**、❌不擅自给药 |
| **患者走失** | ①院内广播/安保联动 ②留守集合点 ③通知家属与机构 | ❌不擅自扩大搜索范围致自身脱岗 |
| **材料遗失**（尤其病理切片） | ①立即全面寻找并报告 ②通知顾客与机构 ③启动保险理赔与协商 | ❌不隐瞒、不拖延 |
| **要求代签手术同意书/法律文书** | **礼貌但坚决拒绝**，清晰告知服务边界；顾客坚持则宁可放弃此单 | ❌不得签署 |
| **要求解读报告/推荐用药** | 明确拒绝，引导其咨询主管医生 | ❌不得提供任何医疗建议 |
| **服务人员与顾客冲突** | ①暂停服务 ②上报机构 ③服务支持人员介入调解 ④全程留痕 | ❌不争执升级 |
| **信息泄露事件** | ①立即止损删除 ②通知服务对象 ③按预案上报 ④承担相应责任 | ❌不隐瞒 |
| **无法履约/迟到/缺席** | ①提前告知 ②启动替补人员 ③按合同违约条款处理 | ❌**不得中途弃单**（曾判赔 5 万元） |
| **疑似黄牛号源** | 立即终止该渠道，仅使用官方预约通道并上报 | ❌不得购买转售号源 |
| **院内意外事件/疏散** | 按医院应急疏散路线引导撤离，优先保护服务对象 | ❌不逆行、不滞留 |

### 6.2 保险与追溯保障

- 机构宜为陪同就医服务**投保相关责任保险**（建议：雇主责任险 + 职业责任险 + 意外险）
- 机构宜建立**服务过程记录与追溯机制**，对关键服务节点进行记录与监测（实时定位打卡、关键环节拍照存档）
- 建议建立 70 岁以上服务对象**家属强制授权**机制

### 执行要点速记

> **用合同锁边界 · 用评估控风险 · 用记录留证据 · 用回访收闭环**

- **合同锁边界**：100% 签约，明确时段、授权范围、不代签
- **评估控风险**：每单必评，评估结果决定服务方案
- **记录留证据**：关键节点打卡、拍照、签收，全程可追溯
- **回访收闭环**：24 小时轻回访 + 2–3 工作日回访 + 复诊提醒
