# 平台定位与服务边界

耍伴是通过「找人帮忙」平台接单的服务提供者，提供同城功能性线下陪伴与代办服务。平台是居间信息服务平台，耍伴与平台是居间服务关系，不是劳动或劳务雇佣关系。

**可以做**：按订单页载明的场景提供陪同、代办、取送、排队、现场协助等已上线服务；在客户授权范围内代为办理事务性手续。

**不可以做**：不从事医疗、护理、法律、金融等需要专业资质的行为；不代替客户做医疗、法律、金融决策；不承接平台未上线的场景；不私下交易或引导客户绕过平台付款。

接单前先看清场景、时间、地点、费用与客户备注。遇到超出能力或资质的需求，礼貌说明边界，引导客户改选合规场景或联系平台客服，不口头承诺平台未列明的服务。

# 接单确认与履约准备

接单后尽快联系客户，确认服务时间、集合地点、服务内容、人数、随行物品与特殊需求。发现订单信息与客户描述不一致时，先联系客户核实，再联系平台客服确认，不擅自变更订单。

履约前完成四件事：一是规划路线与出行时间，预留缓冲；二是检查手机电量、网络、证件与工作标识；三是确认客户紧急联系人及现场联系人；四是了解天气、交通与场所出入口，夜间服务额外确认安全路线。

不带未报备人员同行，不替客户保管贵重物品，不代客户签署任何合同或法律文书。客户临时增加服务内容时，引导其在订单内按平台规则处理，不私下加价或收取现金。遇到无法按时到达、交通中断等情况，第一时间告知客户并申请改派或取消，不失联、不拖延。

# 时间变更与夜间服务

客户临时变更时间或地点时，先查看订单规则与可变更窗口：能自助修改的，引导客户在订单页操作；不能修改的，说明规则并联系平台客服，不私下改单、不口头承诺补偿。

耍伴自身无法履约时，应尽早告知客户与平台，按规则申请改派或取消，说明原因并保留沟通记录。失联、爽约、虚假到达都会影响信用分与后续接单权限。

夜间服务（23:00—7:00）执行更严格的安全标准：出发前确认地址与场所性质，告知紧急联系人行程，保持手机畅通；不单独进入封闭、陌生或存在安全风险的场所；不饮酒、不搭载客户私家车远行。遇到尾随、威胁、骚扰等情况，立即停止服务，撤离到安全区域并拨打 110，同时联系平台与紧急联系人。夜间费用以订单页为准，不临时加价。

# 价格与费用争议

所有费用以订单页与平台规则为准。耍伴不得口头加价、不得额外收取现金、不得引导客户私下转账，也不得擅自减免或承诺返现。

客户对费用有疑问时，先出示订单明细，逐项说明计费项目与服务时长；解释不清或客户不认可的，暂停争议动作，联系平台客服介入，不与客户争执、不堵门、不扣留客户物品。

需要代垫费用时，仅限订单规则允许的项目，留存发票或支付凭证，并在订单内按平台流程发起结算；不私下与客户对账。服务结束后及时提交费用凭证，避免事后争议。

# 隐私、沟通与信用评价

客户住址、联系方式、证件、病历、工作单位等信息仅用于本次履约，不拍摄、不录音、不转发、不向第三方透露。服务记录按平台要求填写，不把客户信息发到社交平台或群聊。

沟通保持尊重与克制：不评判客户的生活方式，不打听与服务无关的隐私，不添加客户私人社交账号进行骚扰，不向客户推销平台外服务。

信用分与评价影响接单权限、优先级与保证金规则。收到差评或投诉时，先核对订单时间线、沟通记录与凭证，按平台申诉流程提交证据；不骚扰客户、不要求客户改评价、不诱导好评。确有服务失误的，按平台规则承担责任并改进。

# 突发情况与违规红线

遇到突发疾病、意外受伤、治安纠纷或人身威胁，先保障客户与自身安全：立即拨打 120 或 110，联系客户家属与平台客服，保留现场记录与凭证；不自行处置超出能力范围的事项，不擅自离开。

遇到地址错误、客户失联、物品损坏、信息不符等情况，暂停履约并联系客户与平台，按规则留存照片、时间与沟通记录，不擅自处置客户物品。

以下行为属于平台红线：私下交易或引导客户绕过平台付款；虚假宣传、刷单、虚假评价；索要或收取额外费用；骚扰客户；泄露客户隐私；代替客户做医疗、法律、金融决策；伪造到达或服务记录。触线将按平台规则处罚，情节严重的移交有关部门。
