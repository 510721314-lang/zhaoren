- **E-6.59【台账真值必须与代码实测对齐】** tech-debt 台账中的路径/计数/行数是治理依据，代码路径迁移（如 `_shared/`→`scripts/`）、基线计数变化、源文件行数变化后，**必须同步用实测值订正台账对应数字**，禁止台账与真实代码脱节。本轮订正实例：P3-1 baseline 路径 + 计数（200→204，补 generated_at=2026-11-21、增量门 +4）、P3-38 confirm-flow 行数（549→545，总 566 行 2026-11-25 实测）。**订正纪律**：改完必须 grep 残留旧值为 0（如 `_shared/silent-catch`、基线 `200`、`confirm-flow 549`），否则视为未订正干净。已同步落入 project_memory Engineering Conventions。
- **E-6.60【时区/日期前缀 bug 的云端实证法】** 修复时区类 bug（如单号日期前缀 UTC→北京时间 P3-26）后，用云端真实数据实证，流程：①`tcb db nosql dump <collection>` 导出 JSONL；②大文件（>100KB）**禁用 `ConvertFrom-Json`**（会超时移后台），改用 `[System.IO.StreamReader]` 逐行读 + 正则提取关键字段（order_no 前缀 8 位数字、created_at 时间戳）；③转北京时间核对（`new Date(ts + 8*3600*1000)`）；④修复前后分组对照。本轮 P3-26：order_main 387 条有效，修复后（北京日期 ≥20261109）凌晨建单（北京 0-7h）5/5 前缀匹配北京时间，修复前（<20261109）凌晨建单 14 条仅 8 条匹配（旧 bug 预期对照）。**PS5 陷阱**：`Where-Object prefix -eq bj_date` 简写会把 `bj_date` 当字面量导致恒不匹配，必须用脚本块 `Where-Object { $_.prefix -eq $_.bj_date }`。
- **E-6.61【门禁阈值用环境变量夹具验证，不改生产文件】** 给 `check-rules-size.js` 这类支持环境变量切换根目录的门禁加阈值后，用临时目录夹具验证边界，不污染生产规则：①建临时 rules 根（`New-Item -ItemType Directory`），放最小 front-matter 文件 + 构造超阈值 `## N.` 章节；②`$env:RULES_ROOT='<tmp>'; node scripts/check-rules-size.js` 分别跑「低于水位 / 超 50%(warn) / 超 80%(fail)」三种夹具；③断言输出关键字（`[SECTION-CAP]` / `[SECTION-WARN]` / 点名节+字节+上限）+ exit code（warn 不阻断 exit=0，fail 阻断 exit=1）；④验证完删临时目录。本轮 P3-44 实测 11/11 pass：§9 超 80%→CAP fail、§8 超 50%→WARN 不被升级成 CAP、7000B 在 warn/fail 之间→只 warn 不阻断、targetBytes 缺失时整段跳过不崩。通用：任何有环境变量切换根的门禁，都可用此法做边界黑盒验证。
- **E-6.62【CloudBase 静态托管访问排障三要点】** 用户报 admin-web 静态托管「无法访问」时，先排除这三个**非故障项**：①测试域名（`*.tcloudbaseapp.com`）会弹「页面访问提示」风险页（内容未审核），需等倒计时 / 点「确定访问」才进登录页——不是白屏；②地址栏直接访问 `/api` 是 **GET 请求**，网关只接 POST，返回 `{"ok":false,"code":"not_found"}` 是**正常响应**，非故障（用 POST 带 key 实测后端正常）；③根路径走 CDN 可能缓存旧构建 HTML，先让用户 `Ctrl+Shift+R` 强制刷新，再看 F12 Network/Console。本轮 2026-11-25 实证：服务端无故障，SPA 登录页正常渲染、后端 POST 正常响应。已同步落入 project_memory Lessons Learned。
