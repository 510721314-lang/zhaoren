### 明确不勾（截图其余全部）

- **用户信息（微信昵称、头像…）**：不勾。grep `getUserProfile` / `getUserInfo` / `chooseAvatar` / `open-type="chooseAvatar"` → **0 处**；昵称手填、头像走 `chooseMedia`（`profile.js:493`）。
- **摄像头**：不勾。全项目 `<camera>` **0 处**；`chooseMedia` 按官方对应关系归「选中的照片或视频信息」（技能 `mp-privacy-release` 线索一）。
- **相册（仅写入）权限**：不勾。无 `saveImageToPhotosAlbum`。
- 其余不勾：发票信息、通讯录（仅写入）、蓝牙、选中的文件、磁场/方向/加速/陀螺仪传感器、剪切板、微信运动数据、日历（仅写入）权限、地址、麦克风、所关注账号、车牌号、邮箱。
- 全部依据：上述 API 在 `miniprogram/` **0 处命中**（2026-11-08 实测）。

## 三、11 条用途文案（逐条填，缺一条即驳回）

| 类型 | 用途描述（可直接粘贴） |
|---|---|
| 位置信息 | 你发布需求、接单、进行安全报备，或查看附近地图并开启位置共享时，获取你当前所在位置，用于按距离展示附近需求、计算履约距离与位置共享。仅在上述场景触发时获取，不在后台持续定位。 |
| 选择的位置信息 | 你在发布需求、接单设置或订单沟通中选择服务履约地点时，使用微信地图选点器，用于填写与确认服务地点。 |
| 选中的照片或视频信息 | 你主动选择或拍摄照片时，用于设置头像、发布图文内容、上传履约凭证与爽约凭证。仅上传你选中的图片，不读取相册其余内容。 |
| 手机号 | 你在发布需求、填写代发人或紧急联系人时主动填写的手机号，用于订单联系、履约沟通与平台安全风控。平台加密存储、展示时脱敏（138****1234）；接单方仅可见脱敏号码，完整号码由平台按订单需要核验后使用。 |
| 设备信息 | 你使用小程序时产生的设备品牌、型号、操作系统版本与平台类型。仅用于安全审计、异常排查与故障定位，不采集唯一设备标识符（不含 OAID/IMEI/IDFA）。 |
| 身份证号码 | 仅在耍伴入驻实名认证时收集，AES-256-GCM 加密存储，仅用于实名核验与纠纷取证，不用于其他目的。 |
| 操作日志 | 你在小程序内的关键操作记录（登录、发布、接单、订单状态变更等），用于安全审计、异常排查与纠纷取证，按平台规则定期清理。 |
| 发布内容 | 你主动发布的需求内容、博客图文与图片，用于展示、匹配与订单履约，仅对你设定的可见范围公开。 |
| 订单信息 | 你在本平台下单产生的订单编号、场景、时间、地点、金额与履约记录，用于订单流转、结算、信用分管理与纠纷处理。 |
| 自定义 ① 通讯内容 | 订单沟通中的文本消息内容。仅作为 IM 功能业务数据，用于双方沟通与服务纠纷取证；四确认完成前仅允许系统模板消息；消息按平台规则过期自动清理。 |
| 自定义 ② 紧急联系人信息 | 仅在耍伴入驻时要求填写紧急联系人姓名、电话与关系，仅用于平台风控与紧急求助（SOS）场景，由平台管理员按需查看并留痕。 |

> 关键：**只勾类型不填用途 = 头号驳回原因**；描述必须精确到业务动作、第二人称。
