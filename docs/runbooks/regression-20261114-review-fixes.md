## 2. A 组 · F10 加时金额冻结（核心，双机）

> 修复口径：加时确认后**只加时长不加金额**（`total_fen`/`fee_fen`/`partner_income_fen` 冻结），云端与前端文案统一「加时暂不计费」。修复前 hourly 加时会把未付金额并进结算基数。

**A1 加时申请面板文案（A 机，hourly 单 S3）**
- [ ] 点「⏰ 加时申请」→ 面板顶部提示行为：**「加时按原单价折算 · 参考单价 ¥X/小时 · 对方确认后合并进结算」**（现状文案，含已知残留，见 §7；判据：面板能正常打开、可选 1-12h、可填原因即可）
- [ ] fixed 单（A7 时机顺带）：面板提示为「一口价订单加时不加价 · 仅延长服务时长 · 对方确认后合并进结算」

**A2 提交申请（A 机，hourly，选 2h + 原因 ≥10 字）**
- [ ] 提交成功，详情页出现加时在途横幅：「⏰ 加时申请 +2小时」——**横幅只显示小时数，不显示金额 ¥**

**A3 加时确认后时长延长、金额不变（核心，B 机操作）**

**A4 确认通知文案（A 机）**
