## 4. 判定口径（避免误判）

| 现象 | 判定 |
|---|---|
| 按下元素**无任何视觉变化**（无缩放/变暗） | 记为**失败**，上报 §5（注明机型 + 浅色/深色） |
| 反馈变化极轻微、肉眼难以分辨 | 记为「**存疑**」，换另一台机型复测或截图放大比对；不要直接判通过 |
| 暗色下选中态显示为浅色实绿（#F0FBF4）而非半透明 | 记为**失败**（token 暗色值未生效），上报 |
| 今日格被冲成浅绿（实心绿丢失） | 记为**失败**（`is-today` 优先级被 `is-active` 覆盖） |
| 按压反馈有，但原有点击行为失效（不跳转/不切换） | 记为**失败**（`hover-class` 不应影响 `bindtap`） |
| 发送键冷却态出现可点的缩放反馈 | 记为**失败**（禁用态不应给可点暗示） |
| 文案/布局与本文描述略有差异但功能正常 | 记为「通过（描述差异）」并备注实际表现 |
