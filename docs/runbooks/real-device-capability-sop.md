# 真机能力链路验证 SOP（模拟器不可达项）

> 生成日期：2026-11-16
> 目的：明确哪些能力**无法在微信开发者工具模拟器**中验证，给出每项的真机验证步骤、预期结果与回执采集方式。
> 配套：`docs/runbooks/pre-release-filing-checklist.md`（隐私/接口权限填报）、`docs/runbooks/realdevice-regression-20261101.md`（批次回归清单）、`tests/e2e/smoke-pages.js`（模拟器可达项冒烟）。

## 1. 模拟器可达 vs 不可达

| 能力 | 模拟器 | 真机 | 说明 |
|---|---|---|---|
| 页面路由 / UI 渲染 / 数据绑定 | ✅ | ✅ | `npm run test:e2e` 覆盖 45 页 |
| 云函数调用（已登录态） | ✅ | ✅ | 模拟器可用 mock_openid |
| 登录（wx.login → 自定义登录态） | ⚠️ 部分 | ✅ | 模拟器可走 mock，但真机登录态链路须验 |
| 模拟支付（payment-mock） | ❌ | ✅ | 收银台「模拟支付」按钮须真机点击 |
| 定位（wx.getLocation） | ❌ | ✅ | 模拟器返回固定坐标，真机须验 GPS |
| 选点（wx.chooseLocation） | ❌ | ✅ | 模拟器无地图交互 |
| 订阅消息（subscribeMessage） | ❌ | ✅ | 模拟器不弹授权框、不下发消息 |
| 授权头像昵称（getUserProfile） | ❌ | ✅ | 模拟器不弹微信授权弹窗 |
| 手机号（getPhoneNumber） | ❌ | ✅ | 本项目表单手填，未调此接口（见下） |
| 相册/摄像头（chooseMedia） | ⚠️ 部分 | ✅ | 模拟器可选文件，但真机权限弹窗须验 |
| 上传/下载（cloud.uploadFile） | ⚠️ 部分 | ✅ | 模拟器可传，但真机网络/进度须验 |
| 拨号（紧急求助） | ❌ | ✅ | 模拟器不调起电话 |
| 隐私协议弹窗 | ❌ | ✅ | 模拟器不触发 `wx.onNeedPrivacyAuthorization` |

## 2. 真机验证 SOP（逐项）

### 2.1 登录链路
- **前置**：体验版已上传，真机扫码进入
- **步骤**：
  1. 清除小程序缓存（微信 → 我 → 设置 → 通用 → 存储空间 → 清理缓存）
  2. 进入小程序 → 触发登录（首页未登录态 / 我的页）
  3. 观察是否走 `wx.login` → `wx.cloud.callFunction` 获取 openid → 写入 storage
- **预期**：登录后 `bootstrap.isLoggedIn()` 返回 true；我的页显示头像昵称
- **回执**：开发者工具 Network 面板查看 `wx.login` + 登录云函数请求/响应

### 2.2 模拟支付
- **前置**：存在一笔 S0 待支付订单
- **步骤**：
  1. 订单详情 → 去支付 → 收银台
  2. 确认页面有「模拟支付，不产生真实扣款」显著提示
  3. 点击模拟支付
- **预期**：订单状态 S0→S2；`pay_transaction` 落 `is_mock:true` 流水
- **回执**：`node scripts/tcb-query-order.js --order-no <ORD...>` 查 `status` + `pay_transaction.is_mock`

### 2.3 定位（getLocation）
- **前置**：`requiredPrivateInfos` 已声明 `getLocation`；mp 后台接口权限已开通
- **步骤**：
  1. 首页 → 附近需求 / 附近地图
  2. 首次进入应弹位置授权框
  3. 授权后列表按距离排序
- **预期**：`getLocationSafe` 返回真实经纬度；附近列表非空且距离合理
- **回执**：真机 vConsole 查看 `getLocation` 返回值；拒绝授权时应有降级 toast

### 2.4 选点（chooseLocation）
- **前置**：发布页 / 接单确认页
- **步骤**：
  1. 发布需求 → 点击「选择地点」
  2. 地图选点 → 确认
- **预期**：返回的 address/lat/lng 正确回填；发布成功后需求详情展示该地点
- **回执**：真机截图选点结果；云端 `demand.location` 字段核对

### 2.5 订阅消息
- **前置**：`sub_msg_templates` 四模板（grab/urge/comm/paid）已配置且 `miniprogram_state=formal`
- **步骤**：
  1. 触发需要订阅消息的动作（如接单、支付、催单）
  2. 观察是否弹「订阅消息」授权框
  3. 勾选「总是保持以上选择」→ 允许
- **预期**：动作完成后收到对应模板消息（通知中心 / 微信服务通知）
- **回执**：`node scripts/tcb-scan-submsg.js [天数=3]` 查 `sub_msg_send_logs` 对应 key 的 status

### 2.6 授权头像昵称（getUserProfile）
- **前置**：登录后首次编辑资料 / 入驻耍伴
- **步骤**：
  1. 我的 → 编辑资料 → 头像
  2. 应弹微信头像昵称授权
- **预期**：授权后头像昵称回填；写入 `user_account`
- **回执**：真机截图授权弹窗 + 回填结果

### 2.7 相册/摄像头（chooseMedia）
- **前置**：隐私指引已勾「相册/摄像头」
- **步骤**：
  1. 发布需求 → 上传图片
  2. 选择「拍照」或「从相册选择」
- **预期**：首次调用弹系统权限框；选择后图片上传成功并预览
- **回执**：真机截图上传结果；云端 fileID 核对

### 2.8 上传/下载
- **前置**：2.7 已通过
- **步骤**：
  1. 上传图片后查看预览
  2. 订单详情下载凭证（如有）
- **预期**：上传进度条正常；下载文件可打开
- **回执**：真机截图；`wx.cloud.uploadFile` 返回 fileID

### 2.9 紧急求助拨号
- **前置**：订单内紧急求助 / 无单自由求助
- **步骤**：
  1. 订单详情 → 紧急求助 → 拨打联系人
  2. 无单：我的 → 紧急求助 → 仅上报
- **预期**：拨号调起系统电话；上报落 `safety_report` + `platform_event(P0)`
- **回执**：真机截图拨号界面；`platform_event` 集合查 P0 事件

### 2.10 隐私协议弹窗
- **前置**：`__usePrivacyCheck__: true`；隐私指引已配置
- **步骤**：
  1. 清除缓存后首次进入小程序
  2. 调用需隐私授权的接口前应弹隐私协议
- **预期**：弹窗展示隐私指引摘要；同意后接口可调用
- **回执**：真机截图隐私弹窗

## 4. 与模拟器冒烟的分工

- **模拟器（`npm run test:e2e`）**：45 页路由可达性 + `page.data()` 非空 → 每次提交前必跑
- **真机（本 SOP）**：上表 10 项能力链路 → 提审前 + 每次涉及相关能力改动后必跑
- **云函数契约测试（`npm test`）**：服务端逻辑正确性 → 每次提交前必跑

## 5. 证据归档（G2）

每次真机/模拟器验证后，证据必须落盘到 `docs/design/evidence/regression-<YYYYMMDD-HHMM>/`：

- `receipts/`：云端回执（`tcb-query-order.js` 等输出）
- `report.md`：结果表（编号｜能力｜设备｜结果｜截图｜回执｜备注）
