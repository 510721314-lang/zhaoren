## 4. 判定口径（避免误判）

| 现象 | 判定 |
|---|---|
| 弹窗文案与本文不一致但语义一致 | 记为「通过（文案差异）」并在备注写实际文案 |
| 点按钮无任何反应 | 记为**失败**，抓 Console 报错（见 §5） |
| 提示在「选完地点/填完原因」之后才出现 | 记为**失败**（未满足「不进编辑态」） |
| S2 变更相关用例点按钮直接弹「距履约不足 1 小时」 | 造数开始时间太近，属前置数据问题，**重造单**后再测 |
| 投诉后仍未冻结（D3 未弹） | 先确认订单是否真的进入争议（详情页有争议卡）；仍不冻结记为**失败**并上报 |
