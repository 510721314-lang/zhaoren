# 地图找TA · 位置标记策略

> 目标：明确「需求发布者 / 耍伴」在地图上的标记规则，指导 nearby-map 页与后续迭代。
> 关联代码：`miniprogram/pages-v2/nearby-map/*`、`cloudfunctions/user-login/index.js`（地图三 action）。

## 1. 数据来源与可见前提

- 位置来源：`user_account.map_gps`（进地图页时 `report_map_gps` 上报实时坐标）。
- 可见前提（双向对称）：
  - 双方都开启 `allow_map_share`（各自控制「TA 能否通过地图找到我」）。
  - 定位 15 分钟有效（`nearby_map_list` 过滤超时者）。
  - 剔除自己。
- 未开共享 / 定位过期 / 未上报 → 对方地图不显示。

## 2. 角色标记策略

| 观察方 | 对方角色 | 地图 Marker | 点击卡片角标 | 操作 |
|---|---|---|---|---|
| 耍伴看地图 | 需求发布者 | 🔵 蓝色定位针 `marker-user.png` | `👤 发单用户` | 定向邀请帮忙 / 承接 |
| 耍伴看地图 | 另一耍伴 | 🟢 绿色定位针 `marker.png` | `🧭 耍伴` | 查看详情 / 邀请 |
| 需求发布者看地图 | 耍伴 | 🟢 绿色定位针 `marker.png` | `🧭 耍伴` | 查看详情 / 邀请帮忙 |
| 需求发布者看地图 | 另一发布者 | 🔵 蓝色定位针 `marker-user.png` | `👤 发单用户` | 展示（频道对齐）|

### 图标语义
- 🟢 绿色针：耍伴（服务供给侧）。
- 🔵 蓝色针：需求发布者（用户侧）。
- 选择逻辑：`marker.iconPath = p.is_partner ? marker.png : marker-user.png`（`nearby-map.js loadNearby()`）。

## 3. 状态与时效

| 状态 | 表现 | 规则 |
|---|---|---|
| 在线(live) | 实心亮色 | 定位 < 15 min |
| 离线/过期 | 不显示 | ≥ 15 min 由后端过滤 |
| 待选增强 | 渐变半透明 | 可选：定位老化(2-15min)降透明度 `(可选)` |

## 4. 隐私与安全

- 开启共享 = 显式同意暴露实时位置；关闭即清空 `map_gps`（根除残留定位）。
- 后端仅返回 `allow_map_share:true` 且定位有效者，同时剔除调用者自己。
- 可选风险缓解（改版时评估）：
  - 返回模糊坐标（±500m 栅格）防精确定位被薅；
  - 非附近(>N km)仅显示方向与距离，不显示精确点。
