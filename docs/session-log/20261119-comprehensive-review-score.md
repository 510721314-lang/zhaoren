✓ 主包 574.7KB + pkg-low 分包 192.9KB，pages-v2 分层；✓ 无页面裸调自家后端（统一走 app.js `cloudCall` 封装，WRITE_RE 写类动词表精细化零重试）；✓ 登录态统一（bootstrap + globalData 双通道清理）；✓ git 锚点完整（commit 链 + deploy-log + 部署前 bundle 归档）；✓ `.trae/rules` 常驻治理 + `check-secrets` 门禁禁密钥入库；✓ envId 唯一来源 envList.js。
扣分：**无 TypeScript / 接口返回类型定义**（原生 JS 项目）−1.5；safety.js 页面直连第三方 HTTP（第三方 API 不走 cloudCall 属合理豁免，仍记轻微）−0.5。

### 2. 功能完整性与主链路（17.5/20）
✓ 核心链路端到端实证（REGISTRY #180：发布→接单→四确认 8/8→模拟支付→履约→评价，订阅消息落库对账）；✓ 13 态订单状态机 + 超时规则 + 信用分 + 四确认，服务端强校验；✓ 异常分支守卫密集（三轮评审 22 项修复多为守卫类：`close_has_active_orders`/`account_restricted`/`sr_free_cooldown`/CAS 状态守卫等）；✓ 门禁 verify:offline EXIT=0（A/B 455 用例 + manifest 87 文件/1180 用例）。
扣分：真实支付未接（MVP 模拟支付口径，但按框架“支付/确认”闭环口径记账）−1；#182/#183/#184 云端行为抽验挂账未清 −1.5。

### 3. 性能体验（13/18）
✓ 主包 574.7KB（优于 ≤1.5MB 建议线）；✓ 骨架屏 10 个页面（实测 grep）；✓ 图片 lazy-load 已启用（index/square/partner-detail/blog）；✓ 云函数保温触发器（zz-warmup 7-22 点每 15 分钟）缓解冷启动。
扣分：**首屏 <1.5s 无实测数据**（zhaoren-perf-baseline 技能已备但未跑出基线报告）−1.5；长列表未用 recycle-view 虚拟滚动（当前量级可控）−1；真机反复进出内存测试未系统做过 −1；setData 传输体积无性能面板核查记录 −1.5。

### 4. 稳定性与容错（10/12）
✓ 幂等与并发防护是全项目最强项：blog_like 唯一索引 + isDupKeyErr、订单状态 CAS 流转（禁非法迁移并记日志）、写类请求零重试防重试风暴（WRITE_RE，今日真机验证）；✓ 超时 12s + 读类重试 2 次；✓ onPageNotFound 兜底 reLaunch。
扣分：**app.js 缺全局 `onError` / `onUnhandledRejection` 上报**（实测 grep 仅页面级零散处理，框架明列项）−1.5；接口 500/空数据兜底页覆盖度未系统核查 −0.5。

### 5. 安全（13/15）
✓ 后端校验一切：金额分单位双整数禁浮点、信用分门槛服务端拦截、场景白名单服务端校验、青少年 200 元上限服务端校验；✓ 无硬编码密钥（check-secrets 门禁脚本）；✓ 手机号三态加密脱敏（phone_enc/hash/mask）+ 注销 PII 清理（R3-3 修复）；✓ UGC 先审后发（IM 四确认前仅模板消息 + 文本过安全检测；blog 发帖/评论封禁拦截）；✓ 登录失败锁定（login_locked）+ admin-web 网关留痕限频 5 条/10min。
