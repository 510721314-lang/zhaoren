## 二、主体与账号（企业主体注册）

### 2.1 前置材料（企业方准备）
| 材料 | 说明 |
|---|---|
| 营业执照 | 三证合一，经营范围须覆盖本项目（生活服务/居民服务/家政/陪诊类） |
| 对公账户 | 认证与支付打款验证用 |
| 法人身份证 | 正反面 + 手持照 |
| 管理员微信 | 绑定了企业信息、可扫码的本人微信 |
| 企业邮箱 | 用于平台通知（不用个人邮箱） |
| 企业对公打款能力 | 部分认证流程需小额打款验证 |

### 2.2 注册路径
1. 打开 [微信公众平台](https://mp.weixin.qq.com) → 立即注册 → **小程序**（不是公众号）
2. 选择主体类型：**企业**（不支持个体户就选个体工商户，但部分类目资质不同）
3. 填写企业信息 → 邮箱激活 → 完善主体信息（营业执照号、法人、管理员）
4. 完成**微信认证**（付费 300 元/次，按年收取；含小程序+公众号共享？——小程序单独认证）
   - 认证方式：法人微信扫码确认 或 对公账户小额打款验证
   - 认证通过后可：改名称、开通支付、申请类目资质、备案

### 2.3 名称与简介
- 名称建议与项目一致（如「找人帮忙」），**不可与已注册/商标冲突**，提交后需审核
- 简介需真实描述服务内容，避免夸大
- **注意**：名称若含行业词（如「陪诊」「家政」），可能触发类目资质核验，需提前备齐资质文件

## 三、类目与资质（本项目重点）

本项目涉及多场景（就医陪诊 W1、生活协助 W8、出行陪伴 W10 等），**类目选择决定审核与合规**。

### 3.1 建议主类目
| 场景 | 建议类目 | 是否需要资质 |
|---|---|---|
| 就医陪诊 | 医疗-陪诊服务 或 生活服务-家政 | 可能需相关服务资质/平台承诺函 |
| 学习陪伴 | 教育-在线教育/教育信息服务 | 视内容定 |
| 生活协助/出行陪伴 | 生活服务-家政/居民服务 | 一般无需特殊资质 |
| 线上陪伴 | 社交/工具 | 需注意内容合规（见 3.3） |

### 3.2 资质文件准备（若有要求）
- 经营范围含「居民服务/家政服务」的营业执照
- 若涉医疗陪诊：平台《服务范围声明》《免责声明》+ 与医院/机构无绑定关系声明
- 若涉培训辅导：相应教育资质或平台责任书

### 3.3 内容合规红线（线上陪伴/即时沟通）
- 明确拒绝色情、诈骗、赌博等违法内容（本项目已有 block_words 敏感词）
- 未成年人保护：本项目已有「未成年人禁止交易」条款，需在类目审核中体现
- 线下见面类服务：需有安全提示与免责（项目已有 redline 夜间红线、安全中心）

## 四、企业认证（微信认证）
- 认证入口：公众平台 → 设置 → 微信认证 → 申请

## 五、ICP 备案（必做，2023 年后新小程序强制）

### 5.1 政策要点
自 2023 年 9 月 1 日起，依据工信部《关于开展移动互联网应用程序备案工作的通知》，**所有新上架小程序必须完成 ICP 备案**，否则无法发布。

### 5.2 备案流程
1. 微信公众平台 → 设置 → 基本设置 → **小程序备案**（或「ICP备案」入口）
2. 填写主体信息（企业：营业执照、法人、联系方式）——会自动带入认证信息
3. 填写小程序信息：名称、服务内容、服务器所在地
4. 提交 → 平台初审 → 管局审核（通常 1-20 个工作日）
5. 备案通过后获得备案号，需在**小程序页脚展示**（「粤ICP备xxxx号」等）

### 5.3 本项目服务器备案注意
- 若使用**腾讯云 CloudBase 默认域名**（`*.tcloudbase.com`），服务器所在地按腾讯云节点（如上海）填写
- 若绑定**自有域名**（见第八节），域名需先完成**域名 ICP 备案**（云厂商备案控制台），再绑定到 CloudBase

### 6.2 request 合法域名白名单（公众平台配置）
小程序正式版只能访问白名单域名。需要添加：
| 用途 | 域名 | 说明 |
|---|---|---|
| 云函数 HTTP 触发 | `https://cloud1-d9gkefwcp5c777088-1482004365.ap-shanghai.app.tcloudbase.com` | 本项目后台 admin-web 网关 |
| 逆地理编码 | `https://apis.map.qq.com` | 腾讯位置服务（本项目已用） |
| 云存储 | `https://xxx.tcb.qcloud.la`（自动） | 云开发自动白名单 |

配置入口：公众平台 → 开发管理 → 开发设置 → 服务器域名 → request 合法域名（最多 30 个）。
**注意**：不配置则正式版 wx.request 全部失败（开发工具「不校验合法域名」勾选只是本地绕过）。

### 6.3 socket / upload / download 合法域名
- 本项目 IM 用云开发（非自建 WebSocket），一般无需单独配置
- 若后续接第三方聊天/上传，需对应配置 socket/download/upload 域名

### 6.4 自定义域名（可选，推荐商用）
CloudBase 默认域名在部分场景（如备案展示、品牌形象）不合适，可绑定自定义域名：
1. 购买域名 → ICP 备案
2. CloudBase 控制台 → 云函数/静态托管 → 域名绑定 → 配置 CNAME 到腾讯云
3. 在公众平台合法域名白名单中替换为新域名

## 七、隐私合规（微信官方强制）

### 7.1 用户隐私保护指引（公众平台必填）
入口：公众平台 → 设置 → 基本设置 → **用户隐私保护指引**（或「隐私协议」）
本项目必须声明以下**信息收集项**（对照项目实际）：
| 收集项 | 触发场景 | 用途 |
|---|---|---|
| 微信 openid | 登录 | 身份标识 |
| 手机号（getPhoneNumber） | 手机号登录 | 账号绑定 |
| 地理位置（getLocation/chooseLocation） | 发布/接单/履约 | 距离与位置校验 |
| 紧急联系人信息 | 耍伴入驻 | 风控/SOS |
| 实名证件信息 | 实名认证 | 合规核验 |
| IM 文本消息 | 聊天 | 业务数据 |
| 设备信息/日志 | 全链路 | 安全审计 |

> 本项目 `app.json` 已声明 `__usePrivacyCheck__: true` 与 `requiredPrivateInfos: [getLocation, chooseLocation]`，且隐私政策/用户协议文案已内置（legal 块），但**公众平台侧的用户隐私保护指引表单必须手动填写**，与代码声明一致。

### 7.2 隐私政策与用户协议
- 本项目已内置：服务协议、隐私政策、免责声明、费用自理承诺书、宠物授权书、场景免责声明（后台 Legal 页可编辑）
- 上线前需确保公众平台「用户隐私保护指引」内容与项目内文案一致

### 7.3 敏感信息脱敏
本项目已完成：导出接口脱敏（phone/idcard/openid）、后台展示掩码。正式商用建议复查一次所有对外接口无明文敏感字段。

## 八、真实支付接入（替换 payment-mock）

### 8.1 前置条件
- 企业主体小程序 + 微信认证 + 类目通过
- **微信支付商户号**：在 [pay.weixin.qq.com](https://pay.weixin.qq.com) 申请，需营业执照、对公账户、法人信息；费率按行业（生活服务类通常 0.6%）
- 商户号与小程序 appid 绑定（商户平台 → 产品中心 → AppID 授权）

### 8.2 本项目代码替换点
| 现实现 | 替换为 |
|---|---|
| `payment-mock` 云函数（mock_pay/mock_refund/mock_tip/mock_ins/withdraw/fast_withdraw） | 云开发「微信支付」能力（`cloud.cloudPay.unifiedOrder` / `refund`）或微信支付 API |
| 前端 pay 页 | 调起 wx.requestPayment |
| 提现/结算 | 商户平台企业付款到零钱 或 结算到银行卡 |

### 8.3 支付合规注意
- 支付回调验签（本项目需新增回调云函数）
- 退款走正规退款 API，不手动改订单
- 资金流水留存（本项目已有 pay_transaction 等表，需接入真实流水）
- **支付开关**：`payment_visible`（admin_config）与真实支付接通后调整

### 9.2 提审操作
1. 开发者工具 → 上传（需登录有权限的账号，版本号+备注）
2. 公众平台 → 版本管理 → 开发版本 → 提交审核
3. 填写：功能页面、测试账号、类目选择（与 3.1 一致）
4. 审核周期：通常 1-7 个工作日；类目资质不齐会驳回

### 9.3 常见驳回点（本项目易踩）
- 陪诊类：无医疗资质声明被驳 → 按类目要求补《免责/范围声明》
- 线上陪伴：涉陌生人社交被要求加实名/举报入口 → 本项目已有实名+举报+紧急求助，需在提审说明中强调
- 支付模拟：**mock 支付在正式版会被驳回** → 必须接真实支付后再提审

### 9.4 发布
- 审核通过 → 版本管理 → 发布（全量/分阶段）
- 发布后建议立即真机回归（正式环境）
