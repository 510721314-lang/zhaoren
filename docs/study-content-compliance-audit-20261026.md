## 3. 医疗表述中性化对照表

| 场景 | 源文措辞 | 判定 | 课程写法（允许） |
|---|---|---|---|
| 服务定位 | 「诊断、治疗、用药等一切医疗决策由医务人员作出」 | 保留 | 医疗决策由医务人员及服务对象（或监护人）作出，陪诊师不参与 |
| 服务边界 | 「检查结果判读」「参与医疗操作」「调整用药方案」 | 保留（禁止项） | 明确写「不得判读检查结果 / 不参与医疗操作 / 不调整用药方案」 |
| 医嘱 | 「记录医嘱」 | 允许（1.5.2 第 7 项） | 客观记录医生意见原文，不解读、不执行、不代替决策 |
| 取药 | 「取药时核对药品名称、规格、数量、用法用量，说明用药时间、禁忌」 | 需中性化 | 核对姓名、药名、规格、数量并交还本人；用药问题请其咨询医生/药师，不自行解释或建议 |
| 用药 | 「给药」「执行医嘱」 | 禁止 | 改为「提醒按医生/药师交代办理」「转达医嘱原文」；不代服药、不增减药量 |
| 诊疗建议 | 「提供医疗建议」 | 禁止 | 改为「可提示其向医生咨询」「不判断病情、不推荐治疗方案」 |
| 检查/治疗 | 「引导至治疗区域」「检查陪同」 | 允许 | 仅限陪同、引导、排队、传递资料；不进入医疗操作环节 |
| 急救 | 「实施心肺复苏、AED」 | 有条件允许 | 先呼叫医护人员/120；仅持急救证人员按规范施救，不实施超出能力范围的处置 |
| 宣传 | 「优先挂号」「优先检查」「走后门」「保证治愈」 | 禁止 | 不出现任何疗效、号源或结果承诺 |
| 心理/情绪 | 「心理治疗」「提供心理咨询」 | 禁止 | 改为「倾听、安抚、陪伴」；需要时转介专业机构 |

### 3.1 课程写作允许动词

陪同、引导、排队、领取、代取、记录、转达、提醒、核对、上报、呼叫、安抚、说明规则、留存凭证。

### 3.2 课程写作禁用指令

给药、执行医嘱、作出诊断、开具处方、调整用药、实施治疗、推荐药品/保健品、保证治愈、优先挂号、走后门、代替客户做医疗/法律/金融决定。
