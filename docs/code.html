五、W1 就医陪诊专项SOP（GB/T 47801—2026 全对齐）

服务前（第6条人员要求 + 第7条边界）
  • 耍伴完成基于国标的专项培训 → 考核（满分100，≥80分通过）
  • 未通过：暂停接单，7天后补考1次；连续3次未过 → 取消W1场景资格（不可恢复，其他场景不受影响）
  • 接单前系统实时校验认证状态：有效可接 / 暂停·补考等待期按钮置灰
  • 用户下单勾选《就医陪诊免责声明》，耍伴接单前勾选同声明 → 双签凭证入库
  • 订单级责任险一单一保自动投保；服务前1天联系确认；患者既往病史/过敏史/行动能力加密采集；履约清单（病历本/医保卡/检查单）确认
服务中（第8条安全保障 + 第9条信息保护）
  • GPS到院签到 → 挂号取号 → 候诊陪同 → 就诊在场（仅记录、不参与医患沟通）→ 缴费取药 → 化验单/报告代取封装 → 药品材料逐项清点交接 → 结束打卡
  • 安全报备每30分钟（国标第8条）：位置+环节+简述+可选照片；超5分钟家属预警、超15分钟客服介入
  • 越界拦截：尝试解读报告/建议用药 → 弹窗警告并记录violation_event；尝试代签医疗文件 → 直接冻结订单升级人工
  • 隐私脱敏（国标第9条）：证件号/病历号中间脱敏展示；诊断原文仅存加密库、耍伴端仅见摘要；影像加密存储、90天后清理
服务后（第10条评价体系 + 医嘱留存）
  • 医嘱按国标格式结构化留存（就诊时间/科室/医嘱要点/复诊提醒/用药清单），仅存摘要，下次复诊一键调取形成健康档案
  • 材料交接逐项照片留档，双方电子签字确认；责任险在保期内可理赔
  • 评价按国标第10条五维度执行（见第九节），评价结果反向驱动耍伴再培训
《就医陪诊免责声明》核心内容（双端展示，对齐国标第7条）：本服务仅提供挂号排队、取号取药、医嘱记录、就诊在场陪同等生活辅助，不提供任何医疗行为，包括但不限于：诊断、治疗、用药建议、检查报告解读、医患沟通翻译、代签医疗文件、代做治疗决策。服务过程中产生的医疗结果与耍伴及平台无关。

七、里程碑引擎与安全报备机制

  • 通用里程碑引擎：耍伴上报达成凭证（照片+定位+时间戳）→ 推送需求者确认 → 15分钟未响应系统自动确认并留痕（24h内可申诉）→ 有异议进IM协商，协商失败转客服仲裁 → 最终里程碑达成进待验收 → 里程碑节点支持分段结算（AA制场景按比例分账）。
  • 安全报备差异化配置：W1每30分钟（国标第8条硬性要求，超时5分钟家属预警/15分钟客服介入）；W7常规30分钟、危机事件后提升至15分钟且后续3笔订单强制客服全程监控；W8里程碑节点+贵重物品交接四确认；W10全程GPS轨迹留痕、偏离自动预警；W11以通话全程录制+AI审核替代报备。

八、资金结算设计（含 W2 AA制SSOT方案）

主链：需求者支付 → 平台托管账户（非耍伴账户）→ 里程碑推进 → 验收确认 → T+1结算至耍伴 → 平台扣阶梯佣金留存。退款联动：释放档期、退优惠券、撤销信用分变更、保单退保；W1责任险保费由佣金覆盖，出险平台先行赔付再向责任方追偿。

  • W2 AA制SSOT（单一事实源）：所有资金往来必须经平台账本记账，每笔变动生成流水号可追溯；服务费与场地费/咖啡费等AA支出分别记入SSOT账本、各自支付各自份额，AA支出需上传消费凭证（小票照片）方可结算。
  • 耍伴不得私下收取现金/微信转账——AI与客服监控私下交易话术，识别即触发红线R3-4，按V3分级处置。
