线上陪伴服务SOP简化文档

面向用户阅读｜包含真人陪伴与AI陪伴两种服务形式

一、什么是线上陪伴服务

线上陪伴是通过文字、语音、视频线上开展的情感陪伴与生活关怀服务，分为真人陪伴师和AI人工智能陪伴两种。

⚠️重要提示：它不等于心理咨询、心理治疗、看病开药，也不提供理财建议。如果您有心理疾病、身体疾病，请前往医院或者找正规心理机构。

风险分级说明（平台会评估您的状态）

  • 🟢一般：情绪平稳，只需要倾听聊天陪伴，正常提供服务。
  • 🟡需关注：情绪低落、焦虑明显。会多给予安抚，同时提示您可以寻求专业帮助。
  • 🔴高风险：有自残、自杀、伤害他人想法，或者遭遇重大财产损失。平台会立刻启动危机干预，联系紧急联系人，必要时报警，引导您找专业机构。

二、可以做什么 & 绝对不能干什么

✅ 可以提供的服务

  1. 倾听倾诉，情感陪伴、情绪安抚鼓励
  2. 生活常识、健康养老知识的提醒科普
  3. 老年人定期问候聊天、精神慰藉
  4. 兴趣话题聊天，正常休闲互动
  5. 识别出您有心理、法律、看病需求，引导您去找正规专业渠道
  6. AI陪伴会主动提醒您使用时长，告知是AI机器人

❌ 红线禁止行为（遇到请保留证据向平台投诉）

  1. 不可以做心理治疗、看病诊断、开药给医疗建议
  2. 不传播色情低俗、擦边内容，不做暧昧性暗示对话
  3. 不能骗您、诱导充值、诱导打赏、情感操纵
  4. 不能诱导您沉迷线上陪伴，让您放弃现实生活社交
  5. 不给未成年人提供虚拟伴侣、虚拟亲属这类虚拟亲密关系服务
  6. 不聊美化自残、自杀、暴力、危害国家安全的内容
  7. 不套取、不泄露您的个人隐私信息

四、每个环节用户须知

阶段1：下单和需求沟通

  • 平台会公示清楚服务内容、价格、投诉渠道，不会虚假宣传，不会说可以“心理治疗、包治好”。
  • 下单之后，平台会在1小时内响应联系您。
  • 会收集必要信息：年龄，必要时登记紧急联系人；用来做风险评估，建立服务档案。
  • 未成年人：未满14周岁使用服务，需要监护人同意；开启未成年人模式。禁止给未成年人提供虚拟伴侣。

阶段2：签署服务协议

  • 正式服务前，需要阅读线上服务协议，写明服务时长、价格、双方权责、隐私保护、投诉渠道。
  • 您随时可以查看协议、消费明细，平台不能私自涨价、乱改收费。

阶段3：正式线上陪伴（真人 / AI）

👤真人陪伴师：

  • 开场会自我介绍，报工号，说明本次服务安排。
  • 主要是倾听陪伴，不会评判指责您；如果发现您过度依赖线上，会温和引导您多现实社交。
  • 快到约定结束时间，会提前告知；您随时可以说结束，对方不能纠缠挽留。

🤖AI人工智能陪伴：

  • 必须明确告诉您它是AI机器人，不可以假装真人。
  • 连续使用满2小时，弹窗提醒您休息。
  • 发现您有沉迷倾向，会弹窗提醒，引导现实社交。

👵老年人陪伴：常规建议每月至少问候陪伴1次；过节、恶劣天气会适当增加关怀。

⚠️高风险情况如何处理

如果聊天中您流露出自伤、自杀、伤害他人想法，或者遭遇被骗钱财重大损失：

  1. 陪伴师不会继续闲聊，会立刻做情绪安抚，鼓励您寻求现实帮助。
  2. 会联系您登记的紧急联系人；情况危急会直接报警。
  3. 引导您找医院心理科、正规心理热线等专业渠道，做好记录存档。
  4. 不会替您做心理治疗，危机全过程平台留存记录。

阶段4：服务退出结束

  • 您可以随时要求停止服务！不管是打字、语音说退出，平台都要立刻停止对话，不能持续纠缠挽留。
  • 平台要提前通知您服务即将到期；如果平台要停止这项服务，也需要发布公告告知用户。

阶段5：回访、评价与投诉

  • 服务结束后24小时内，平台进行回访，了解您的感受，收集意见。
  • 平台有公开投诉入口，您的投诉会被完整记录并且反馈处理。涉及违法情况，平台会上报主管部门。

五、隐私数据保护说明

  • 您聊天对话、个人信息属于隐私，没有经过您同意，平台不可以泄露，也不能随便给第三方使用。
  • 您有权复制、删除自己的聊天记录。
  • 您的聊天敏感数据，要训练AI模型，必须取得您单独同意，不能偷偷拿去训练。
  • 未满14周岁孩子的信息，需要监护人同意才能处理，还需要合规审计。
  • 工作人员离职，要对您的信息做保密或者删除处理，不能私自带走客户聊天记录。

七、给用户重要提示

  1. 线上陪伴只是情感陪伴，不能替代医生看病，也不能替代正规心理咨询师。身体、心理有疾病一定要找线下专业机构。
  2. AI陪伴要确认对方明确说明是机器人，如果隐瞒身份属于违规。
  3. 未成年人禁止使用虚拟伴侣、虚拟亲属类服务，未满14周岁使用服务，需要监护人同意。
  4. 不要相信陪伴师私下诱导充值、打赏、私下转账，所有消费走平台官方渠道。
  5. 出现自残自杀等危险想法，请优先联系家人、心理热线、报警求助，平台会配合干预，但不能完全解决您的心理危机。
  6. 遇到红线违规行为，请保存聊天截图，使用平台投诉渠道反馈。

八、简单责任说明

平台提供线上陪伴服务，严格遵守国家网络、个人信息保护相关法律。

服务只做情感陪伴，无法完全消除用户自身心理疾病、现实生活带来的风险。高风险场景平台会按流程联系紧急联系人、报警、引导专业机构。

平台对陪伴师做背景审核、岗前培训考试，上岗需要80分以上考试合格。
