### 1.3 现状痛点（对应三条需求）
- **P1** 新增场景下拉含已配置项 → 易重复配置、易把 A 场景文案覆盖成 B 场景
- **P2** 已配置场景仍可改下拉 → 文案可被「挪」到别的场景，归属失控；且场景免责无版本/无回滚
- **P3** 保存粒度粗 → 改一处影响一片；无独立「重置」，误改只能整页刷新

## 2. 需求清单

### R1 · 新增场景下拉仅列「未配置免责声明」的场景
**优先级**：P1 ｜ **范围**：纯前端

**规则**
- R1-1 候选集 = `scene_list` − `legal_scene_disclaimers` 已有 key − 当前其他编辑行已选 code（互斥）
- R1-2 无候选时：「+ 新增场景」按钮**禁用**，悬浮/下方提示「所有场景均已配置免责声明」
- R1-3 `scene_list` 为空：按钮禁用并提示「请先在运营配置中创建场景」
- R1-4 已配置但 `scene_list` 中已下线的 code（孤儿）**不进候选**，但在列表中保留，标「已下线」并允许删除

**交互**
- 下拉 placeholder：「选择场景（仅显示未配置项）」
- 下拉项展示 `name（code）`

**验收**
| 编号 | 用例 | 期望 |
|---|---|---|
| A1 | 已配置 W1 → 新增 | 下拉不含 W1 |
| A2 | 同时新增两行 | 第二行不含第一行已选 code |
| A3 | 全部场景已配置 | 按钮禁用 + 提示文案 |
| A4 | W1 从 scene_list 移除 | 列表中 W1 标「已下线」且可删除，下拉永不出现 |

---

### R2 · 已配置场景只读 + 场景免责版本管理
**优先级**：P1 ｜ **范围**：前端 + `admin-action`

**规则**
- R2-1 **已配置行的场景 code 只读**（以标签展示，不可改下拉）；确需换场景 → 删除该条后重新新增
- R2-2 **版本化**：每次保存生成新版本；可查看历史、可回滚；旧版本归档不删（与 R3 的保存语义一致，见 D1）
- R2-3 版本键：`doc_type='scene_disclaimer'` + `scope=<scene_code>` + `version` 单调递增，唯一
- R2-4 **发布双写**：写 `legal_doc` 同时回写 `admin_config.legal_scene_disclaimers` → 上述 3 个云函数**零改动**即可继续工作（与批1a 对 `legal_*` 的双写同构）
- R2-5 生效时机：C 端下次拉取生效（受 `home-action` 缓存 TTL 影响）
- R2-6 删除语义见 D5

**验收**
| 编号 | 用例 | 期望 |
|---|---|---|
| A5 | W1 连续保存两次 | 历史 2 条：v1 归档 / v2 生效 |
| A6 | 回滚到 v1 | 生成 v3（内容=v1），v1/v2 保留 |
| A7 | 保存后回读 | `legal_doc` 与 `admin_config` 文案**逐字一致** |
| A8 | 调 `home-action scene_groups` | 返回文案 = 最新 published |
| A9 | R3 账号访问 | 可读列表；保存/回滚拒绝（仅 R1） |

---

### R3 · 每条法律文档独立的「重置 / 保存」
**优先级**：P2 ｜ **范围**：纯前端（复用既有发布接口）

**规则**
- R3-1 **每个**法律文档编辑区（5 类卡片 + 每条场景免责）各自拥有独立的 `[重置]` `[保存]`，互不影响
- R3-2 「重置」= 丢弃本区未保存改动、回填**当前生效内容**，**不发请求**、不触发确认
- R3-3 「保存」语义 = 见 **D1**；无论哪种，都必须**只作用于本区**
- R3-4 存在未保存改动时，切换菜单/刷新页面需二次确认
- R3-5 保存中禁用本区按钮，防重复提交
- R3-6 保存失败：恢复按钮态 + 展示错误码与可读原因（不静默）

**验收**
| 编号 | 用例 | 期望 |
|---|---|---|
| A10 | 改文档 A 后保存 | 仅 A 产生新版本，B/C/D/E 无变化 |
| A11 | 改后点「重置」 | 内容回到当前生效值；DevTools 无网络请求 |
| A12 | 保存时断言失败（如超长） | 按钮恢复、错误码可见（`legal_too_long`）且**不产生版本** |
| A13 | 两区同时有改动 | 先保存 A，B 的未保存改动**不丢** |

## 3. 数据与接口影响

| 项 | 变更 |
|---|---|
| `legal_doc` | 增字段 `scope`（默认 `''`）；版本唯一键改为 `(doc_type, scope, version)` |
| `legal_doc_publish` | 支持 `scope`；双写映射扩展为「场景 → `legal_scene_disclaimers[scope]`」 |
| `legal_doc_list` | 支持按 `scope` 过滤；返回 `scope` |
| `legal_doc_rollback` | 支持 `scope` |
| （D3）`legal_scene_upsert` | 单条 upsert，替代整块 `config_set`，降低多人并发覆盖 |
| 索引 | `legal_doc (doc_type, scope, version)` 唯一 —— **CLI 不能建，需控制台手动**（台账登记） |
| 兜底兼容 | 旧后台构建仍可整块 `config_set`（保留热修通道）；C 端**零改动** |

## 4. 非功能要求

- **权限**：`legal_doc_list` R3 可读；`publish/rollback/upsert` 仅 R1
- **审计**：每次保存/回滚写 `platform_event`（P2）+ `config_history`；含 `content_sha256`
- **一致性**：双写后回读校验（`legal_doc` vs `admin_config`），漂移即告警
- **回滚**：代码 = 按 commit 重建 `dist` 重新发布；数据 = `legal_doc` 历史版本
- **冻结纪律**：R2 涉及 `cloudfunctions/admin-action` → 需与批 1a 同口径的用户书面授权（提审冻结期禁止业务代码改动）

## 5. 待确认决策点

| 编号 | 决策点 | 选项 | 结论（2026-10-25 用户拍板） |
|---|---|---|---|
| **D1** | 「保存」语义 | A) 保存即发布新版本（二次确认）；B) 存草稿，另设发布按钮 | **A ✅ 保存即发布**（不引入草稿态） |
| **D2** | 场景免责是否复用 `legal_doc` | A) 复用（加 `scope`）；B) 新建集合 | **A ✅ 复用**（加 `scope` 字段） |
| **D3** | 是否新增 `legal_scene_upsert` | A) 新增单条 upsert；B) 沿用整块 `config_set` | **不发新 action**：由 `legal_doc_publish` 承载单条写入并在服务端做 map 合并（减少 action 面） |
| **D4** | 实施时机 | A) 立即（需授权破例）；B) 提审通过后 | **A ✅ 立即全量（U1+U2+U3）**，补授权备忘 |
| **D5** | 删除已配置场景的语义 | A) 发布 v(N+1) 空内容 + 从 config 移除；B) 仅从 config 移除 | **A ✅**（新增 `legal_doc_retire`，保留版本史） |
| **D6** | 5 类文档编辑形态 | A) 保留弹窗 + 卡片按钮；B) 卡片内联 | **A ✅ 弹窗编辑 + 每文档独立按钮** |

### 5.1 R3 按钮落点（按 D6 落地口径）

| 对象 | 「重置」位置 | 「保存」位置 |
|---|---|---|
| 5 类法律文档 | 编辑弹窗底部（丢弃改动、回填当前生效内容，零请求） | 编辑弹窗底部（`保存 vN+1`，二次确认后发布） |
| 每条场景免责 | 该行内（同上） | 该行内（调用 `legal_doc_publish` + `scope`，仅影响该行） |

> 说明：D6 选择弹窗形态后，「每条文档独立按钮」体现为**每个文档各自的弹窗内独立 重置/保存**——互不共享状态、互不影响；场景免责因是行内编辑，按钮直接落在行上。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 整块 `config_set` 并发覆盖 | 两人同时改，后写覆盖先写 | D3 采纳 upsert + 保存前回读版本号（乐观锁） |
| 双写漂移 | `legal_doc` 与 `config` 不一致 → C 端与后台显示不同 | 保存后自动回读比对；漂移写 `platform_event` 告警 |
| 场景 code 下线 | 孤儿免责文案残留 | R1-4 标「已下线」可删；列表提示 |
| 「保存即发布」误操作 | 线上文案被错误替换 | 二次确认弹窗 + 审计留痕 + 可一键回滚 |
| 冻结期改云函数 | 提审风险 | D4 默认 B；若选 A 须补授权备忘 |
