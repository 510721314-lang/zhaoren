## 5. 目标用户画像与高频场景（全部提取，无扩写）

**画像（艾媒 [S2] + 蓝皮书 [S8]）**
- 付费决策人：26–45 岁城市中青年中产子女（占决策 55.08%、代付 63.56%）；新一线/二线为基本盘（58.49%）。
- 服务体验人：60–79 岁居家老人（89.95%）；超六成家庭存在双老需求；超六成受访家庭有患慢病老人。
- 心理特征：23.76% 有孤独感、26.4% 有抑郁症状（蓝皮书）；情绪衍生躯体症状 47.14%、隐性焦虑 42.21%（艾媒）。
- 付费性格：高接受度（91.86%）、高价格敏感（主流带 101–800 元/次）、重实效轻营销；最大顾虑是性价比（49.38%）与信任（30.86%）。

**高频场景（按提取数据排序）**
1. 常态化情绪陪伴与心理疏导（需求占比 65.33%）[S2]
2. 就医陪同：挂号、排队、陪检、取药（认知度 94.27%；超九成老人需要陪诊 [S11]；就医心理陪伴 41.61%、医患沟通辅助 41.31%）[S2][S11]
3. 生活协助：陪买菜、逛公园、代办（"贴心随行"类，50–60 元/h 实测）[S22]
4. 双老家庭组合服务（超六成家庭双老需求）[S2]
