## 二、架构评估

**整体：合理、配置驱动、边界清晰，但前后端均为原生 JS 无类型保障。**

| 维度 | 评估 | 证据 |
|---|---|---|
| 前端 | 原生 WXML/WXSS/JS，无框架；分包预加载（pkgLow 等）；暗黑模式 / 隐私检查 / 定位已声明 | `miniprogram/app.json`，主包 20 + 分包 19 = 39 页 |
| 后端 | 云函数 + 文档库（38 集合），统一 `callFunction({action})` 接口形态；`_shared` 跨函数共享 | `cloudfunctions/admin-action/action_export.js` |
| 配置治理 | 运行时 SSOT 为云端 `admin_config`，前端仅兜底；场景 / 集合 / 默认值多副本门禁对齐 | `miniprogram/config/index.js`（标 V15.1 可运营参数唯一来源） |

## 三、质量与工程化（本项目最强项）

以门禁链和真值治理为核心的工程纪律，在同规模项目中属上乘。

| 单元测试 | **1264 用例 / 0 fail**，90 个测试文件 14,545 行 | ★★★★☆ |

| 真值治理 | 台账头部计数有门禁守护（P3-47 一/二/三期），防计数与真值脱节；云端回读为最高真值（§44 / §7） | ★★★★★ |

**短板**：
- 单测在**入口契约层 + 核心业务纯函数**覆盖扎实（2026-11-27 实证复核）：四确认状态机 45 用例（含附录A#4「变更项双确认、其余三项保持」、幂等防卡单、CAS 回滚）、取消退款编排 20 用例（含事务补偿路径、老单 fund 兜底、信用分钳制）、退款梯度 `cancelRefundFen` 与扣分梯度 `cancelCreditDelta` 均含档位边界（含等于）/自定义 cfg/非法回退/NaN 防御/默认值一致性；**真正不足的是端到端真机回归**（未做 IDE 全页编译 / E2E / iOS+Android 全链路真机留证）。
- 无静态类型检查（tsc），接口字段变更靠人工 + A/B 守护，存在隐性契约漂移风险。
- `_shared` 多副本机制虽有门禁守护，本质是物理副本（P2-4 决策不拆），长期维护成本高于 monorepo workspace。

## 六、综合评级

| 维度 | 评级 |
|---|---|
| 工程纪律与门禁链 | **A（优秀）** —— 30 项离线门禁 + 真值治理 + 双代理评审，同规模项目中罕见 |
| 代码质量与可维护性 | **B+（良好）** —— 原生无类型是主要扣分项；巨页为已知接受项 |
| 测试覆盖 | **B（良好偏上）** —— 数量与防假通过做得好，核心业务覆盖扎实；真机全链路覆盖不足 |
| 架构合理性 | **B+** —— 配置驱动、边界清晰；`_shared` 多副本为有意权衡 |
| 上线就绪度 | **B-（接近但未达）** —— 门禁全绿，但缺真机全链路 + 真实能力切换 + IDE 编译验证 |
| 技术债健康度 | **A-（优秀）** —— 56/63 结案，剩余为可接受 / 有触发条件的挂账 |

**一句话总结**：这是一个**工程化纪律远超平均水平、质量基线扎实可信**的生产级小程序项目；当前阻塞上线的不是代码质量（门禁已全绿），而是**真机覆盖、真实能力切换（支付 / 人脸 / 短信）等"上线前必须人工完成"的环节**。代码侧风险低，运营 / 资质 / 真机侧是剩余主战场。

## 七、建议（按优先级，供参考）

1. **提审前必做（人工）**：iOS+Android 真机全链路回归（登录 / 发布 / 匹配 / 订单 / 模拟支付 / IM / SOS / 后台管理），留证入 FUNCTION-REGISTRY。
2. **资质到位后切换**：mock 支付 → 真实微信支付、mock 人脸 → 真实核身、补短信 SDK（P1-5 / P1-6）。
3. **长期演进（可选）**：关键云函数 action 逐步引入 TypeScript 或 JSDoc 类型注解，提升接口契约编译期保障。
4. **监控告警**：经 2026-11-27 实证复核，三项均已落地——①order-timer 心跳（order-timer/index.js L207 写 `error_scan_heartbeat_at`，[check-heartbeat.ps1](file:///c:/zhaoren/scripts/check-heartbeat.ps1) 检查 <30min，ops-runbook 登记为每日巡检）；②订阅消息配额耗尽降级（order-timer L290/L397 catch 吞掉不阻断主流程）；③广场/附近分页上限（home-action `HOME_GROUP_SIZE=8`/`SCENE_PAGE_SIZE=50`，前端 `CONFIG.PAGING`，square.js 已 `@VERIFIED`）。原"未落地"表述系无证据泛化，已修正。
