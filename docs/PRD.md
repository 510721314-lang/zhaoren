> 本页只做文档体系路径适配，**不复制、不摘录、不反推**任何 PRD 内容。

## 为什么不放正文

- `scripts/check-prd-drift.js` 硬编码 `PRD/PRD.md`，搬移会直接打断漂移门禁。
- 全仓（常驻规则、runbook、skill、交接稿）大量引用该路径，搬移等于制造断链。

## 使用约定

1. **改需求** → 直接改 [PRD/PRD.md](../PRD/PRD.md)，在对应章节内增补并标注日期与依据，不在本页续写。
2. **本页禁止承载需求正文**；与本页描述冲突时，一律以 PRD 正本为准。
3. **PRD 与代码冲突** → 以代码为准，并在 [CHANGELOG.md](CHANGELOG.md) 留痕（沿用既有纪律）。
4. 文档侧索引见 [README.md](README.md)。
